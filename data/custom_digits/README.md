# Original handwritten images

The supplied notebook contains saved results for nine handwritten photographs,
but those original image files were not included in this repository.

To repeat that optional experiment, place your own original `.png`, `.jpg`, or
`.jpeg` files here, then run `python -m scripts.train_model` from the repository
root. The training command copies them into its working directory and executes
the notebook's original preprocessing and prediction cells.

Do not present the MNIST example in `examples/` as a student-created photograph.
