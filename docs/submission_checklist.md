# Submission checklist

## Repository

- [ ] Open the GitHub repository without being signed in and confirm it is public.
- [ ] Confirm that `main` contains the final code, artifact, examples, and README.
- [ ] Confirm that `develop` and feature branches are retained.
- [ ] Install the requirements in a Python 3.11 virtual environment.
- [ ] Start Uvicorn and check `/health`, `/predict`, and `/docs`.
- [ ] Run the tests and review the reported metrics and limitations.
- [ ] Make sure the `.venv`, downloaded cache, credentials, and local tools are
      not tracked in the final version.
- [ ] Review every submitted line and the assignment's authorship/AI rules.

## Video (student action required)

- [ ] Record your own presentation with your face visible and good lighting.
- [ ] Stay within ten minutes and cover every topic in section 5.4 of the PDF.
- [ ] Demonstrate installation/execution, successful prediction, and validation.
- [ ] Explain task organization, branches, technical choices, and limitations.
- [ ] Upload to Google Drive and enable Anyone with the link / Viewer.
- [ ] Verify access without signing in.
- [ ] Add the actual video link to README and commit it before final submission.

## AVA (student action required)

- [ ] Submit the public GitHub link and real video link in the Module 2 project task.
- [ ] Meet the PDF's deadline: 3 November 2026 at 22:00; confirm its timezone
      with the course because the PDF does not specify one.
- [ ] Keep a record of the submission confirmation.
- [ ] Do not update the repository after submission until the grade is issued.

The repository's code checks do not replace the video, AVA submission, or the
student's demonstration of technical understanding.
